# RescueMesh demo

Live demo of RescueMesh, the CSCE 4411 Distributed Systems term project (Group 7, Phase 1): the six lab PCs on one screen. Pick the election mode, set the load, and mute or kill a node. The project's own Rust election, bid scoring and planner run in the browser as WebAssembly. Network, load and queueing are modelled and calibrated to the six-PC study, and the study's measured results are shown alongside.

Live page: https://marwanmoh11.github.io/rescuemesh-demo/
